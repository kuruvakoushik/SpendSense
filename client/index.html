Monthly budgets

Analytics

Spending insights

Rule-based insights flag budget overruns, pace issues, and unusual expenses — without machine learning claims.

Privacy-first by design

SpendSense does not use a cloud database. Financial records are stored in a local SQLite file (typically instance/spendsense.db) on the computer running Flask. There are no paid APIs, no external identity providers, and no silent demo transactions.
